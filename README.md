# 🎮 The Last Remedy

A Unity C# game project featuring player movement, interactive gameplay mechanics and a custom game environment.

## 📌 About the Project

The Last Remedy is a game project developed using Unity and C# as part of my Computing work.

The project demonstrates the development of an interactive game using Unity, including player controls, game mechanics, environments and gameplay systems.

It gave me practical experience working with C# scripts inside Unity and developing, testing and debugging gameplay features.

## ✨ Features

- Player movement and controls
- Interactive gameplay mechanics
- Custom game environment
- Collision and physics systems
- Game objects and components
- Unity scene development
- C# gameplay scripts
- User interaction
- Game testing and debugging

## 📂 Project Structure

- `Assets/` – Game assets, scenes, scripts and other project content
- `Packages/` – Unity package configuration
- `ProjectSettings/` – Unity project settings

## ▶️ Running the Project

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add project from disk**.
4. Select the downloaded project folder.
5. Open the project using the appropriate Unity version.
6. Open the main game scene and press **Play**.
